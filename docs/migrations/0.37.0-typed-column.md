# Migrating a consumer to the typed-vector column (`0.37.0`, Phases 417–431)

**What changes.** A `Fuaran.Core.Column` is `{ Name; Data }`, and `Data` is one case of `ColumnData` per
column type, each an immutable `Vector<'T>` of values beside a `Validity` (`AllValid`, or a `Mask` of
`Vector<bool>`, `true` where the row is present). `Column.Cells` and `Column.create` are gone, and
`Column.Type` is derived from the storage. Dates are days since 1970-01-01 (`Vector<int>`), timestamps
are whole epoch seconds (`Vector<float>`) plus an optional fraction scaled to the column's `TimeUnit`,
and `TimestampType` names that unit. A schema is a `Field list`. The wire does not move: every column
document encodes to the bytes it encoded to before. `Cell` remains the scalar read type. The full
record is [`docs/releases/0.37.0.md`](../releases/0.37.0.md), Phases 417, 418, 420, 421, 422, 427 and 431.
This note covers the column. The rest of `0.37.0` is in [`0.37.0.md`](0.37.0.md).

## The edits, one per pattern

| You wrote (`0.36.0` and earlier) | Write instead (`0.37.0`) |
|---|---|
| `{ Name = n; Type = IntType; Cells = cells }`, `Column.create n IntType cells` | `Column.ofCells n IntType cells`, which is a `Result`: it refuses a cell its type cannot hold, as the `TypeMismatch` that `Table.validate` named. Prefer a typed builder where you hold values: `Column.ofInts n (Vector.ofList xs) AllValid` (`ofFloats`, `ofBools`, `ofStrs`, `ofDecimals`, `ofDates`, `ofTimestamps`) |
| a column with absent rows | `Column.ofInts n (Vector.ofList xs) (Validity.ofList present)`. `ofList` / `ofArray` / `ofVector` answer `AllValid` when no row is absent. The value under an absent row is ignored |
| `c.Cells \|> List.map f` | `Column.tryInts c \|> Option.map (Vector.map f)` (`tryFloats`, `tryStrs` and the rest). Where a row may be absent, ask `Column.isPresent i c`, or match `Column.validity c` and skip the `AllValid` case |
| `c.Cells \|> List.item i`, `List.length c.Cells` | `Column.cell i c` (O(1), `Null` for an absent or out-of-range row), `Column.length c` |
| `c.Cells` handed on as a `Cell list` | `Column.toCells c`. This is the bridge for code you have not moved yet. It allocates a cell per row, so do not use it on a hot path |
| `{ c with Cells = cs }`, `{ c with Type = t }` | rebuild the column: `Column.ofCells c.Name t cs` |
| a raw array for interop (a native call, a JavaScript typed array) | `let b = Vector.Unsafe.borrow v` gives `b.Array`, `b.Offset` and `b.Length`. **Never write through it.** Copy with `Vector.toArray` if you need a mutable array. To build without a copy, use `Vector.adopt arr` and do not touch `arr` again |
| `TimestampType`, as a value or a pattern | `TimestampType TimeUnit.Seconds` / `TimestampType _` (`Milliseconds`, `Microseconds`, `Nanoseconds`) |
| date / timestamp text in, `ofDates n texts v` / `ofTimestamps n texts v` | `Column.ofCells n DateType cells`. Or build from integers: `TemporalText.tryDays text` gives a day, `TemporalText.tryInstant unit text` gives `(seconds, fraction)`, then `Column.ofDates n days v` / `Column.ofTimestamps n unit seconds fraction v` |
| .NET dates in or out | `Column.ofDateOnlys n values`, `Column.ofDateTimeOffsets n unit values` (a `Result`: it refuses an instant finer than `unit` and does not round it), `Column.tryDateOnly i c`, `Column.tryDateTimeOffset i c`. These are .NET only; under Fable, read the integers |
| ordering timestamp text with `String.CompareOrdinal` | `Cell.compare` or `TemporalText.compareInstants` (chronological across units) |
| `Validity.all n`, a `Vector<bool>` passed as a validity, `Column.validity c` read as a vector, `Validity.presentCount v` | `AllValid`, `Validity.ofVector v` (or `Mask v`), `Column.mask c`, `Validity.presentCount (Column.length c) v` |
| `[ "a", IntType ]` as a schema, `(name, ty)` over an entry | `[ Field.create "a" IntType ]`, `f.Name` / `f.Type` |
| a `Column` or `Table` in a `Set`, a `Map` key or `compare` | equality only: `Vector` has no order. Key by `c.Name` |

**The `Vector` contract.** This is a stability promise (`STABILITY.md`, "The ownership contract of
`Vector`"). No public member writes into a vector. `Vector.ofArray` / `ofList` / `ofSeq` / `init` copy
or build fresh. `slice` is a view over the same storage, never a copy. `adopt` takes ownership without
a copy. `Unsafe.borrow` is the only way to reach the backing array, and the borrower must not write
through it. Under Fable a `Vector<bool>` is packed in a `Uint8ClampedArray` (Phase 431), so read a
borrowed bool element as a condition, never as a value. A consumer that borrows or adopts adds one run
of `Conformance.columnOwnershipLaws` (or `…With` over its own draw) to its suite. That run names any
column whose bytes moved.

## Verify

1. Raise the pin and build with `TreatWarningsAsErrors` off. Every row above except the comparison row
   and the `ofCells` / `ofDateTimeOffsets` refusals shows up as a compile error, so the error list is
   your work list.
2. Search for `toCells` once the build is green. Each hit is a conversion left in place. Keep it only
   where a `Cell` is the value you want.
3. Run your suite. A column built from cells that held a value of the wrong type now fails at
   `ofCells` instead of at `Table.validate`. A timestamp built from unvalidated storage raises at
   `ofTimestamps`.
4. If you borrow or adopt, run `Conformance.columnOwnershipLaws` over your pipeline.
5. A host that reads the wire needs no change for `date` and `timestamp`. Do not emit
   `timestamp_ms` / `_us` / `_ns` until every host you write to decodes them.

## Roll back

Pin the `0.x` you came from. The wire is unchanged in both directions for `date` and `timestamp`
columns, so a document written by either version reads in the other. A sub-second column is the
exception: it does not read in `0.x`.

## Census (2026-10-12, Phase 424)

**Method.** The census is type-resolved. For every downstream F# project whose restored
package graph includes `Fuaran.Core.Column`, or whose sources mention `Cells`, `Column`, `Columns` or
`ColumnCodec`, the project's own compiler command line was taken from MSBuild in a design-time run.
Its F# project references were checked from source. FSharp.Compiler.Service then type-checked it
against the Core version the project pins. A site counts only when the symbol resolves to
`Fuaran.Core.Column`, a field of it, a member of its module, or `ColumnCodec`. A `Cells` member of any
other type does not count. 124 projects in 29 repositories were checked. All but two type-checked
clean, and the two partial checks are noted below. One project could not be restored at its own pins.
Its own sources mention none of the four names, only its vendored build output does. The token
pre-filter can miss one kind of site: a file that reads a column's `Name` through an inferred type
without writing any of the four names. Such a read compiles unchanged at `0.37.0`.

| Repository | Files | Files needing an edit | Construction sites | Read sites | Codec sites |
|---|---|---|---|---|---|
| `fuaran-dotnet` | 32 | 28 | 95 | 38 | 10 |
| `fuaran-live` | 6 | 6 | 14 | 32 | 2 |
| `fuaran-program` | 3 | 1 | 1 | 3 | 4 |
| `fuaran-core-compute` | 40 | 0 (adopted in Phase 423) | 23 | 282 | 66 |
| four private consumers | 19 | 14 | 20 | 46 | 3 |

A site is one source line holding a resolved use, and a record literal over three lines counts three
times. "Needing an edit" means the file uses `Cells`, `Column.create` or a `Type =` record field, and
so fails to compile at `0.37.0`. A codec site (`ColumnCodec`) needs no edit. In `fuaran-live`, two
projects type-checked with errors that were already there at their own pins: 1 in `app` and 26 in
`app/showcase`, the first of each naming a member their pinned packages do not carry. Their counts
are a floor. `fuaran-core-compute` holds 90 `Column.toCells` calls, which are bridge reads and compile
unchanged. Every other consumer project that was checked holds no `Fuaran.Core.Column` at all. Each
owning repository adopts through its own planned work, which cites this note.
