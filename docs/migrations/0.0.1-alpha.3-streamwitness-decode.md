# Migration: `0.0.1-alpha.2` → `0.0.1-alpha.3` — `Result`-typed `StreamWitness.Decode` (Phase 252)

**Breaking change** to one witness field and two functions. Surfaced by the Documents adoption
pilot (finding F3): `StreamWitness.Decode` was the only substrate seam that wasn't
`Result`-returning, forcing adopters to `failwith` on malformed input and discard the typed error.

## What changed

| Surface | Before | After |
|---|---|---|
| `StreamWitness.Decode` | `string -> 'Op` | `string -> Result<'Op, string>` |
| `OpStream.fromJsonl` | `… -> OpRecord<'Op> list` | `… -> Result<OpRecord<'Op> list, string>` (names `line N: <reason>` on a bad line) |
| `OpStream.snapshotFromJsonl` | `… -> Snapshot<'State>` | `… -> Result<Snapshot<'State>, string>` |

No other signatures change. `append` / `verifyChain` / `replay` / `toJsonl` / `snapshotToJsonl` are
unaffected (they never decode).

## The adopter diff

**1. The witness `Decode`** — most domains already have a `Result`-returning decoder, so this gets
*simpler* (drop the exception adapter):

```diff
 let sw : StreamWitness<DocOp, Document, OpRejection> =
     { Apply  = fun op d -> Ops.apply op d
       Encode = Wire.encodeOp
-      Decode = fun s -> match Wire.decodeOp s with Ok o -> o | Error e -> failwith e }
+      Decode = Wire.decodeOp }          // Wire.decodeOp : string -> Result<DocOp, string>
```

**2. `fromJsonl` call sites** — match the `Result`:

```diff
-let records = OpStream.fromJsonl sw jsonl
-// use records …
+match OpStream.fromJsonl sw jsonl with
+| Ok records -> // use records …
+| Error msg   -> // a malformed line, named — recover, don't crash
```

**3. `snapshotFromJsonl` call sites** — same shape (`Ok snap` / `Error msg`).

## Verification

- The chain round-trip is unchanged: `toJsonl` then `fromJsonl` yields `Ok records` equal to the
  originals, and `verifyChain` still holds.
- A line whose op fails to decode now yields `Error "line N: <reason>"` instead of throwing.

## Why

The substrate's credibility rests on "failures are typed data, never exceptions." This was the lone
seam that broke that rule. Aligning it makes a malformed persisted stream a recoverable `Error` on
every host (.NET and Fable alike), with no exception path remaining.
