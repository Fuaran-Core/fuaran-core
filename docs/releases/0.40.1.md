**Slot class: additive.** The patch after the released `0.40.0`. It opens over `v0.40.0`, which is a
consumer's contract, so nothing rides it; the work in this slot is additive, which makes it a PATCH slot, and
a member of a higher class advances it to the `0.41.0` minor rather than riding it ([`STABILITY.md`](../../STABILITY.md),

process, whose binaries the next tag is the first to publish, and Phase 543's `CorpusFile`, which `0.40.0` shipped
internal. The conformance `kitVersion` stamp lines move to `0.40.1` with the slot, and the corpus pin moves to
the re-stamp of the declared copies.
