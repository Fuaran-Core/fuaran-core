### The version note formerly kept in `Directory.Build.props`

_Written beside `<Version>` when the slot was cut, and moved here verbatim by Phase 397._

**0.6.0 (2026-08-21).** every FNV-1a in the spine routes its multiply through a split-half
32-bit form so it computes true 32-bit FNV-1a on BOTH pipelines. Six implementations, not
one: the canonical `Hash.fnv1a`, `OpStream.defaultHash` (the CHAIN hash), `Column`'s
`Schema.fingerprint`, and three duplicates now deleted in favour of the canonical one.
No public surface changed and
.NET values are byte-for-byte unchanged — the pinned vectors enforce that — so a .NET
consumer repins with no source change and no persisted digest moves. MINOR rather than
patch because STABILITY.md makes these functions' VALUES the contract, and under Fable
every value changes: the pre-0.6.0 transpiled multiply overflowed 2^53 and was not FNV-1a.
A patch bump would tell a Fable consumer nothing observable moved, which is false. See
DECISIONS.md D16 and the "Digest changes" entry in STABILITY.md.
