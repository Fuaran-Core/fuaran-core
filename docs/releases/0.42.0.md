### Breaking

- **A structure write is its parent's child-list slot, and a read is of a node's existence** (Phase 625,
  `Fuaran.Core.Ops`, `Fuaran.Core.OpStream.Dag`, `Fuaran.Core.Conformance`; DECISIONS.md D246, amending D106) —
  class breaking (behavioural: `Ops.independent` answers `true` for pairs it answered `false` for). Against a slot
  access a structure write of `p` is a read and a write of `(p, Footprint.childListSlot)` (`"#children"`), so a write
  of any other slot of `p` commutes with an insert into `p`, a move into or out of it and a removal under it, and an
  access of the child-list slot is a `SlotClash` naming it; two structure writes of one parent stay `SameParent`
  alone. A slot access meets the node sets only at a content write (`LeftSlotsRightNode` / `RightSlotsLeftNode`
  carry content-written nodes only): a `Reads` entry is an existence read, which no slot write changes. No skeleton
  verdict moves. The unknown-parent clause meets a child-list slot access as it meets a structure write
  (`Footprint.structural`): a removal or move, whose source parent the pure script cannot name, serialises
  against a domain op that reads or rewrites a child list by slot. New: `Footprint.childListSlot`,
  `Footprint.childListSlots`, `Footprint.structural`. `Conformance.footprintLawsAt` and
  `footprintInLawsAt` gain the child-list law (a pair freed at the child-list slot commutes under the domain's
  `Apply`; a child-list access is named at the slot by `Ops.interference` and `Dag.conflicts` alike) and, where a
  slot access meets a structure write of its node, the `child-list-freed pair` demand (`child-list clash pair`
  beside it where one is drawn). **Migration:** a domain whose footprint declares slot accesses re-runs its census;
  a slot write that can change a node's structural `Children` (or what the domain's admission answers for a child
  of it) also writes `Footprint.childListSlot`; a reader of a node's content declares the slots it reads with
  `readingSlot`, since `reading [ id ]` no longer collides with a slot write of `id`. The UI tier is the first
  consumer to re-measure (fuaran#2645).
