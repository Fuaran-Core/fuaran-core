## 0.46.0 — DRAFT

**Slot class: breaking.** The minor after the released `0.45.0`. It advances the untagged `0.45.1` draft, a PATCH
slot of class additive, which a breaking member does not ride: through the `0.x` line a breaking class advances the
MINOR, which makes it a MINOR slot, and every later member rides it ([`STABILITY.md`](../../STABILITY.md),
"Versioning policy"). No `v0.45.1` tag was cut, so the entries under `0.45.1` ship in `0.46.0`, and its file keeps
them as the record of their class. Phase 722 advances it. The conformance `kitVersion` stamp lines move to `0.46.0`
with the slot, and the corpus pin moves to the re-stamp of the declared copies.

**Each entry of this slot is a file of its own** (DECISIONS.md D274): add one as
`docs/releases/0.46.0/<class>/<name>.md`, with `<class>` one of `breaking`, `additive` or `internal` and `<name>`
`phase-<n>` (`phase-<n>-<word>` for a phase's second entry) or `pr-<n>`, holding the entry's bullet exactly as it
will print, and the act that closes the slot renders the entries here, a section per class.
