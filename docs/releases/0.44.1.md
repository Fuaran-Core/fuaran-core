### Additive

- **The claims ladder gains a fifth assumed class, `witness-obligation`** (Phase 601, `proofs/kit/`, `proofs/`) —
  class additive; no package, wire or conformance surface moves, and every existing ladder reads as before. A
  `witness-obligation` row is a property every implementation of a domain's own witness must answer, which a theorem
  takes as a hypothesis and the witness's own tests discharge: no law of the shipped kit reaches it, so it is neither
  a `domain-obligation` nor a `host-premise`. It names the member in `dischargedBy`, `<Witness>.<member>`, and its
  `evidence.assumption` says what the member answers. `Proofs.Ladder` refuses such a row with no `dischargedBy`, with
  one outside that form or naming a `Conformance.<law>` (that row is a `domain-obligation`), and with a `closes` or a
  `probe`; `Proofs.Coverage` counts it as `witness-discharged`. The ladder summary and the contract section count the
  class (this repository's ladder carries none), the kit template carries one annotated example row, and the kit
  asset's sha moves with `LADDER.md` and the template. **Migration:** none for a package consumer. A ladder that
  already carries rows of this class decodes unchanged once a registry reads the kit at this version, whether or not
  its rows name a `dischargedBy`: a registry refuses only an unrecognised `class`, and the member rule is held by the
  host family of the repository that states the rows.

### Internal

- **A column with no absent row allocates no mask while it is built** (Phase 608, `Column.fs`) — no package

- **A digest copies its input once** (Phase 609, `Fuaran.Core.Text`) — class **internal**: no `api/` or `api/wire/`
  row, no verdict and no vector moves. `Hash.utf8Bytes` sizes one exact array with `utf8ByteCount` and encodes into
  it; the SHA-256 compression reads every whole block straight from its input and pads only the tail in a 64- or
  128-byte scratch; the hex form writes one `char[64]`. `sha256Hex` over a million mixed units allocates 1.36 MB
  where it allocated 9.63 MB, and `sha256HexOfBytes` a constant 728 bytes at every size where it allocated three
  times its input; measured in `benchmarks/results/2026-11-19-ultra9-386h-phase-609.md`.
- **A store load finds its lines in place** (Phase 610, `Fuaran.Core.OpStream`) — `Jsonl.scanRecords` finds each line
  by `IndexOf('\n')`, a `\r` before the `\n` taken as the terminator, and copies each line once, where it rewrote the
  text with `\r\n` read as `\n` and split it. A CRLF text is no longer copied whole: over a 30 MB, 9,844-line store
  the CRLF scan allocates 182.7 MB where it allocated 243.7 MB, and gen2 falls from 0.91 to 0.19 per load; an LF text
  was never copied whole and is unchanged. The lines, their numbers and every refusal and its position are the
  split's, held against the old scan by a sweep. No API, wire byte or conformance file moves.

- **A date or an instant renders into one string** (Phase 611, `TemporalText.fs`) — class **internal**: no `api/`
  row, wire byte or refusal moves. `dateText` and `instantText` write a day or an instant in the canonical range into
  one `char[]` sized to the text and build one string from it, over the civil parts the date accessors share; a day,
  a second of the day or a fraction outside the range keeps the padded text it always had, held against that form by
  new tests at every unit. `dateText` allocates 96 bytes where it allocated 180, `instantText` 128 to 171 where 364

  `benchmarks/results/2026-11-19-ultra9-386h-phase-611.md`.
- **An aggregate over a date, a timestamp or a bool compares the carrier** (Phase 612, `Column.fs`) — class
