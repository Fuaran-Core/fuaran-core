## 0.44.1 — DRAFT

**Slot class: additive.** The patch after the released `0.44.0`. It opens over `v0.44.0`, which is a consumer's
contract, so nothing rides it; the work in this slot is additive, which makes it a PATCH slot, and a member of a
higher class advances it to the `0.45.0` minor rather than riding it ([`STABILITY.md`](../../STABILITY.md),
"Versioning policy"). The performance review wave, Phases 608 to 616, opens it. The conformance `kitVersion` stamp
lines move to `0.44.1` with the slot, and the corpus pin moves to the re-stamp of the declared copies.

### Internal

- **A column with no absent row allocates no mask while it is built** (Phase 608, `Column.fs`) — no package
  surface, wire byte or refusal moves. `TypeOps.fill`, the walk under `Column.ofCells` and the codec's decode,
  allocates the validity mask at the first absent row, with the rows before it present, and answers `AllValid`
  holding no array when none is absent; a timestamp column's two vectors are filled directly, without the pair
  array copied out of before. Measured in `benchmarks/results/2026-11-19-ultra9-386h-phase-608.md`: a ten-cell
  `Column.ofCells` plus `Column.aggregate` allocates 14 % less, and a null-free 100,000-row timestamp decode
  1.7 MB less, with fewer gen2 collections.
- **A digest copies its input once** (Phase 609, `Fuaran.Core.Text`) — class **internal**: no `api/` or `api/wire/`
  row, no verdict and no vector moves. `Hash.utf8Bytes` sizes one exact array with `utf8ByteCount` and encodes into
  it; the SHA-256 compression reads every whole block straight from its input and pads only the tail in a 64- or
  128-byte scratch; the hex form writes one `char[64]`. `sha256Hex` over a million mixed units allocates 1.36 MB
  where it allocated 9.63 MB, and `sha256HexOfBytes` a constant 728 bytes at every size where it allocated three
  times its input; measured in `benchmarks/results/2026-11-19-ultra9-386h-phase-609.md`.
- **The parity table runs the query declaration's refusals under Node** (Phase 699, `Fuaran.Core.Conformance`,
  DECISIONS.md D269) — class **internal**: no `api/` or `api/wire/` row, no verdict and no vector of a family moves.
  107 rows join the public value `ParityVectors.vectors`, appended after every earlier row, one per vector of
  `queryDeclarationLaws`: `queryDecl/read/*` (46, the declaration reader with the admission gate last),
  `queryDecl/admit/*` (34, `QueryRegistry.admit`), `queryDecl/register/*` (4), `queryDecl/validate/*` (14,
  `Query.validateParams`) and `queryDecl/dispatch/*` (9, `QueryRegistry.dispatch`). Each compares a refusal's code
  and path, or its error document without its sentence, and an accepted declaration by the digest of its written
  text; every one of the family's 20 refusal codes is answered by a row, and a census in the test project reads the
  family and names any code left without one. Before this phase no row reached the family, so `0.44.0` was released
  with its Fable value leg unmeasured for it. The receiving gate's value leg reads 665 vectors where it read 558, and
  every one is byte-identical under .NET and Node.
