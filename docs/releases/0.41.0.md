## 0.41.0 — DRAFT

**Slot class: breaking.** The minor after the released `0.40.3`. It opens over `v0.40.3`, which is a consumer's
contract, so nothing rides it; through the `0.x` line a breaking class advances the MINOR, which makes it a MINOR
slot, and every later member rides it ([`STABILITY.md`](../../STABILITY.md), "Versioning policy"). Phases 474 and
549 open it. The conformance `kitVersion` stamp lines move to `0.41.0` with the slot, and the corpus pin moves to
the re-stamp of the declared copies.

### Breaking

- **An inline declaration lays its members on the object holding it** (Phase 474, `Fuaran.Core.Idl`,
  `Fuaran.Core.Idl.Codegen`; DECISIONS.md D220) — class breaking (Fuaran.Core.Idl: record-widening); the wire
  additive. `IdlRecord` gains `Inline` (an inline record's members are keys of its holder; a tagged case whose one
  field is an inline record is a record-payload case) and `IdlUnion` gains `Discrimination`
  (`UnionDiscrimination.Tagged` | `ByPresence` of `KeyedCase { Case; Key; Synthesised }`: a presence-keyed union
  read from the key present, with synthesised members and the both-present refusal `OutOfRange` at the second key).
  `idl.json` omits both at their defaults (`inline`, `byPresence`), so every existing artifact and generated module
  is byte-identical. New: `Declare.layoutErrors`, `IdlUnion.KeyedCase`. The F# module and the interpreter lay them
  out; the JSON schema states their members on the holder; the TypeScript backend, the F* target and
  `Gen.fsharpCodecModule` refuse a vocabulary reaching one, by name. `Diff.Change` gains `TypeLayoutChanged`
  (breaking-wire) and `Snapshot` gains `TypeLayouts`. **Migration:** add `Inline = false` to every `IdlRecord`
  literal and `Discrimination = UnionDiscrimination.Tagged` to every `IdlUnion` literal; give
  `Change.TypeLayoutChanged` an arm in an exhaustive match.
- **A vocabulary declares its keyed positions, and the generated witness has one child enumeration** (Phase 494,
  `Fuaran.Core.Idl`, `Fuaran.Core.Idl.Codegen`, `Fuaran.Core.Conformance`; DECISIONS.md D228) — class breaking
  (Fuaran.Core.Idl: record-widening, for every `IdlField` full-literal construction); the wire additive.
  `IdlField` gains `Keyed` (declared last): a node or node list a kind always carries, marked keyed, leaves the
  generated `children` / `withChildren` and joins `keyedChildren` / `keyedWitness`, on the F# and the TypeScript
  printers alike. `idl.json` and `support.json` write `keyed` only when set, so every existing artifact and every
  unmarked vocabulary's generated module is byte-identical; `Declare.errors` refuses the marker anywhere it
  declares nothing. `Diff.Change` gains `FieldKeyedChanged` (host-surface-only, appended last) and `FieldSnap`
  gains `Keyed`. New: `Conformance.witnessPairLawsAt`, the generated-versus-hand witness pair law.
  **Migration:** add `Keyed = false` to every `IdlField` literal; give `Change.FieldKeyedChanged` an arm in an
  exhaustive match; a domain that holds a named arm keyed by hand marks that field `Keyed = true`, regenerates,
  and may certify the pair with `witnessPairLawsAt`.
- **Host adoption in a family manifest is a record with a case count** (Phase 477, `conformance/`; DECISIONS.md
  D222) — class breaking for a reader of a manifest's `adoption` member; no public type moves (the manifest schema
  is internal). In every self-enumerated manifest Core emits (`apply/`, `refusals/`, `decode/`, `chain/`, `dag/`,
  `merge/`, `diff/`) `adoption.<host>` is `{ "status", "cases", "kitVersion", "sha" }` instead of a status string:
  `status` is `proposed` | `adopted` | `vacuous` | `declined`, `cases` rides a measurement only, and `kitVersion`
  with `sha` name a measurement made in a host's own repository. The writer derives the status, so a leg that
  asserted no case reads `vacuous`; the suite reads every committed manifest back and refuses a bare string and an
  `adopted` entry with `cases: 0`. Every unmeasured entry reads `{ "status": "proposed" }`; Core's own measured
  entries (`fuaran` on `apply/` and the four structural families) read `adopted` with the vectors the suite
  checks. The corpus's `apply/manifest.json` takes the new `skeletonApply` row; other producers' rows are
  untouched. **Migration:** a host flipping its own entry writes the record through Core's exporter, and a tool
  reading `adoption.<host>` reads `.status`.
- **A host's own proof is a ladder row, and a fifth compliance class cites it** (Phase 566, `proofs.json`,
  `docs/`, the tool; DECISIONS.md D233, amending D229) — class breaking for a reader of the compliance contract,
  which `STABILITY.md` says a class or code added is; no package surface moves. A host-proof row (`proved`,
  carrying `repo`, the host) records a proof a host made of its own code against a model here, with its
  `toolchain`, `replay` and `commit` identities and the model it `mirrors`; the first is `spine-escape-quoted`,
  the Rust spine's Creusot proof that its own `escape_bytes` is `WireCanon.fst`'s `quoted`, its transliteration
  gap on the boundary. The ladder family's `host-proof` clause replaces its refusal of every row carrying `repo`;
  the evidence map gives such a row a `host` member and keeps it off the worklist. `host-compliance.json` gains
  the class `proof-replayed` (`toolchain`, `replay`), checked against the row it stands on by four new codes
  (`not-a-proof`, `proof-host`, `toolchain-mismatch`, `replay-mismatch`; 29 in all). **Migration:** a declaration
  of the four existing classes validates unchanged; a projection or tool reading a declaration's classes, the
  verdict's `byClass` or the refusal codes gives `proof-replayed` and the four codes an arm, and a reader of the
  evidence map tolerates the `host` member.

### Additive

- **Four Core-owned structural families over the skeleton witness** (Phase 549, `conformance/`; DECISIONS.md D221)
  — class additive; no public surface moves. `conformance/chain/skeleton-chain.json` (the op-stream chain over
  opaque payloads: append and walk), `dag/skeleton-dag.json` (the op-DAG's content ids, write refusals, heads,
  order, ranks, fold and integrity walk), `merge/skeleton-merge.json` (the common base and `Dag.reconcileMany`
  under `Ops.footprint`) and `diff/skeleton-diff.json` (`Diff.toOpsWith` and `Diff.changes` over the witness
  envelope), each with its own self-enumerated manifest and written by `render chain|dag|merge|diff`. Every
  expectation is computed by calling Core under the canonical profile and SHA-256, and is a function of the
  vector's own input, which the suite re-answers. A spine with no UI tier certifies its chain, DAG, merge and diff
  against them from its first commit; the four language hosts read `proposed`. No corpus copy is declared.
- **Every vector says who answered it** (Phase 478, `conformance/`; DECISIONS.md D223) — class additive for a reader
  that ignores an unknown member, which every host's reader does; no public surface moves (`AnsweredBy` is
  internal). Every emitted vector carries `answeredBy`: `["reference"]`, or `["reference", "model:<Model>"]` when
  the export also ran that extracted F* model on the vector's input and got the same answer — a disagreement fails
  `render`, naming the vector, the model and the proof-ladder row. A `lines` file (`escape/`, `encoding/`) carries
  one header stamp for every line. Model-stamped now: `laws/propagation-laws.json` (73 of 73, `Propagation`),
  `laws/decimal-laws.json` (49 of 75, `DecimalText`), `apply/skeleton-apply.json` (25 of 25, `TreeOps`) and the
  `json` codec refusals (56 of 101, `JsonParse`, re-encoded by the same canonical writer); every
  other vector is reference-only, and docs/conformance-corpus.md names which of those a model could answer. The
  declared corpus copies (`laws/capability-laws.json`, `decimal-laws.json`, `field-laws.json`,
  `propagation-laws.json`, `apply/skeleton-apply.json`) move with the pin. **Migration:** none; a host that reports
  what it certified against can read the stamp.
- **Core derives the evidence a host can offer for every ladder row** (Phase 480, `docs/`; DECISIONS.md D224) —
  class additive; no public surface moves. `docs/host-evidence-map.json`, written with its rendering
  `docs/host-evidence-map.md` by `render evidence-map`, gives every `proofs.json` row, in ladder order, the
  vector families whose cases its model answered (from the `answeredBy` stamps, with the case count) and the
  oracle functions that ask its model (from the oracle's own function table), at the grain of the model. It names
  the proved rows offered neither, grouped by model, as the worklist for new families, and the families no model
  answers. The suite holds both files to the render, and the derivation refuses a stamp or an oracle function
  naming a model no row states. **Migration:** none; a host's compliance declaration names rows from it.
- **A host one unit off any limit bound fails the decode family, by name** (Phase 481, `conformance/`; DECISIONS.md
  D226) — class additive; no public surface moves and no vector moves. The suite now reads every limits vector of
  `decode/` under each bound of its record shifted by one either way, and every vector without a record under the
  nesting cap shifted the same way, and requires each of the twelve simulated hosts to fail a vector, printing which.
  Each bound's vector at it and vector past it already do: the family gains no row just under a bound, which no
  off-by-one host would fail. **Migration:** none.
- **Core states the premises a host must answer, each with a probe** (Phase 483, `proofs.json`, `conformance/`;
  DECISIONS.md D227) — class additive; no public surface moves. The claims ladder's assumed rows are classed from
  four: a `host-premise` row is a premise the models take from the runtime (a UTF-16 string model, shortest
  round-trip float digits, integer width at the int53 guard, FIPS 180-4 SHA-256, a stack for the bounded
  recursion), and names its `probe`, a vector family under `conformance/premises/` written by `render premises`
  with a self-enumerated manifest. A host discharges a premise for itself by reproducing every vector of its
  probe; `docs/host-premises.md` states each premise and what a Rust, Go or Python host does to answer it. The
  evidence map offers each row its probe, and the `Proofs.Coverage` line gains a `host-probed` count. Every host
  reads `proposed`. **Migration:** none for a package consumer. A ladder registry refuses an unrecognised `class`
  (`proofs/kit/LADDER.md`), so a registry reading this ladder learns `host-premise` (and may project `probe`)
  before it reads it.
- **Each host declares its compliance row by row, and Core validates the declaration** (Phase 484, `docs/`, the
  tool; DECISIONS.md D229) — class additive; no public surface moves. A host commits `host-compliance.json`
  (`kind` `hostCompliance`, `docs/host-compliance.schema.json`) naming, for rows of the claims ladder, evidence of
  four closed classes: `vector-certified` (family, cases), `oracle-differential` (model, function, inputs, seed),
  `host-premise` (probe, cases) and `not-covered` (reason). `dotnet run --project tools/Fuaran.Core.Tools --
  compliance <file>` validates it against the evidence map, every family manifest's adoption record and the
  host-premise rows, refusing by one of 25 named codes a row, family or oracle function that does not exist, a
  count the host's adoption record does not carry, a premise discharged on fewer than every vector of its probe and
  a declaration naming another Core version; it prints a canonical verdict with two computed labels, `compliant`
  (every row Core offers evidence for declared) and `parity` (every offered family certified at every vector, every
  offered oracle function differentially tested, every premise discharged). `docs/host-compliance.md` states the
  schema, every refusal and the verdict. **Migration:** none; a host declares when it chooses to.
- **The collecting decoders take a host's decoder at every enumeration, scalar, generic union and absent member**
  (Phase 562, `Fuaran.Core.Idl.Codegen`; DECISIONS.md D230) — class additive; no public type moves, and every
  generated decoder answers as before. Under `Derivation.SpecDecoders` the emitted `CollectingDecoders` gains a
  field per enumeration and per JSON scalar (`String`, `Int`, `Float`, `Bool`), a `Collecting<U>` seam per generic
  union whose one `Decode` is generic in its parameters, and `Absent`, asked at every declared member an object does
  not carry with the holder's name, the key and the object. A host with positional null rules reads through Core's
  token surface, leaves each member null out of the object it builds, and answers it by position in its `Absent`.
  A vocabulary type the record would name twice (`String`, `Int`, `Float`, `Bool`, `Absent`, `Collecting<U>`) is
  refused at generation. **Migration:** none for a host that copies the record (`{ collectingDecoders with … }`);
  a full-literal construction of `CollectingDecoders` adds the new fields; a drift guard over a regenerated module
  re-renders it.
- **The law families carry the adoption record in their own index** (Phase 564, `conformance/`; DECISIONS.md
  D231) — class additive; no public surface moves and no vector moves. `conformance/laws/manifest.json`, written by
  `render laws` with the law files, is the one manifest schema over the five law files this repository emits, one
  row each with its vector count and the per-host adoption record, so a host's measured law cases are written where
  a host reads them. It is written at this repository's home only: in a corpus checkout `laws/manifest.json` is the
  shared index, which `render laws <corpus dir>` still restamps and never replaces, so nothing in the corpus moves.
  `SpineAdoption` names each measurement's own Core version and spine commit, and records the Rust spine adopted at
  every vector of every family with a manifest (`fuaran-core-rs` `0aa91db`). **Migration:** none.
- **Every family a model can answer is stamped by it, or says why not** (Phase 563, `conformance/`; DECISIONS.md
  D232) — class additive; no public surface moves and no answer moves, only `answeredBy`. The export now asks the
  extracted models about the capability laws (`Capability`, 48 of 72), the decimal and field codec cases
  (`WireColumn`, 7 of 12 and 24 of 24), the column codec refusals (`WireColumn` 13 and `JsonParse` 3 of 26), the seam

  corpus copies `laws/capability-laws.json`, `decimal-laws.json` and `field-laws.json` move with the pin.
  **Migration:** none; a host that reports what it certified against reads more model stamps.
- **The Go Core spine is adopted at its first certification, and every manifest takes every spine's entry from one
