## 0.41.0 — DRAFT

**Slot class: breaking.** The minor after the released `0.40.3`. It opens over `v0.40.3`, which is a consumer's
contract, so nothing rides it; through the `0.x` line a breaking class advances the MINOR, which makes it a MINOR
slot, and every later member rides it ([`STABILITY.md`](../../STABILITY.md), "Versioning policy"). Phases 474 and
549 open it. The conformance `kitVersion` stamp lines move to `0.41.0` with the slot, and the corpus pin moves to
the re-stamp of the declared copies.

### Breaking

- **An inline declaration lays its members on the object holding it** (Phase 474, `Fuaran.Core.Idl`,
  `Fuaran.Core.Idl.Codegen`; DECISIONS.md D220) — class breaking (Fuaran.Core.Idl: record-widening); the wire
  additive. `IdlRecord` gains `Inline` (an inline record's members are keys of its holder; a tagged case whose one
  field is an inline record is a record-payload case) and `IdlUnion` gains `Discrimination`
  (`UnionDiscrimination.Tagged` | `ByPresence` of `KeyedCase { Case; Key; Synthesised }`: a presence-keyed union
  read from the key present, with synthesised members and the both-present refusal `OutOfRange` at the second key).
  `idl.json` omits both at their defaults (`inline`, `byPresence`), so every existing artifact and generated module
  is byte-identical. New: `Declare.layoutErrors`, `IdlUnion.KeyedCase`. The F# module and the interpreter lay them
  out; the JSON schema states their members on the holder; the TypeScript backend, the F* target and
  `Gen.fsharpCodecModule` refuse a vocabulary reaching one, by name. `Diff.Change` gains `TypeLayoutChanged`
  (breaking-wire) and `Snapshot` gains `TypeLayouts`. **Migration:** add `Inline = false` to every `IdlRecord`
  literal and `Discrimination = UnionDiscrimination.Tagged` to every `IdlUnion` literal; give
  `Change.TypeLayoutChanged` an arm in an exhaustive match.
- **Host adoption in a family manifest is a record with a case count** (Phase 477, `conformance/`; DECISIONS.md
  D222) — class breaking for a reader of a manifest's `adoption` member; no public type moves (the manifest schema
  is internal). In every self-enumerated manifest Core emits (`apply/`, `refusals/`, `decode/`, `chain/`, `dag/`,
  `merge/`, `diff/`) `adoption.<host>` is `{ "status", "cases", "kitVersion", "sha" }` instead of a status string:
  `status` is `proposed` | `adopted` | `vacuous` | `declined`, `cases` rides a measurement only, and `kitVersion`
  with `sha` name a measurement made in a host's own repository. The writer derives the status, so a leg that
  asserted no case reads `vacuous`; the suite reads every committed manifest back and refuses a bare string and an
  `adopted` entry with `cases: 0`. Every unmeasured entry reads `{ "status": "proposed" }`; Core's own measured
  entries (`fuaran` on `apply/` and the four structural families) read `adopted` with the vectors the suite
  checks. The corpus's `apply/manifest.json` takes the new `skeletonApply` row; other producers' rows are
  untouched. **Migration:** a host flipping its own entry writes the record through Core's exporter, and a tool
  reading `adoption.<host>` reads `.status`.

### Additive

- **Four Core-owned structural families over the skeleton witness** (Phase 549, `conformance/`; DECISIONS.md D221)
  — class additive; no public surface moves. `conformance/chain/skeleton-chain.json` (the op-stream chain over
  opaque payloads: append and walk), `dag/skeleton-dag.json` (the op-DAG's content ids, write refusals, heads,
  order, ranks, fold and integrity walk), `merge/skeleton-merge.json` (the common base and `Dag.reconcileMany`
  under `Ops.footprint`) and `diff/skeleton-diff.json` (`Diff.toOpsWith` and `Diff.changes` over the witness
  envelope), each with its own self-enumerated manifest and written by `render chain|dag|merge|diff`. Every
  expectation is computed by calling Core under the canonical profile and SHA-256, and is a function of the
  vector's own input, which the suite re-answers. A spine with no UI tier certifies its chain, DAG, merge and diff
  against them from its first commit; the four language hosts read `proposed`. No corpus copy is declared.
- **Every vector says who answered it** (Phase 478, `conformance/`; DECISIONS.md D223) — class additive for a reader
  that ignores an unknown member, which every host's reader does; no public surface moves (`AnsweredBy` is
  internal). Every emitted vector carries `answeredBy`: `["reference"]`, or `["reference", "model:<Model>"]` when
  the export also ran that extracted F* model on the vector's input and got the same answer — a disagreement fails
  `render`, naming the vector, the model and the proof-ladder row. A `lines` file (`escape/`, `encoding/`) carries
  one header stamp for every line. Model-stamped now: `laws/propagation-laws.json` (73 of 73, `Propagation`),
  `laws/decimal-laws.json` (49 of 75, `DecimalText`), `apply/skeleton-apply.json` (25 of 25, `TreeOps`) and the
  `json` codec refusals (56 of 101, `JsonParse`, re-encoded by the same canonical writer); every
  other vector is reference-only, and docs/conformance-corpus.md names which of those a model could answer. The
  declared corpus copies (`laws/capability-laws.json`, `decimal-laws.json`, `field-laws.json`,
  `propagation-laws.json`, `apply/skeleton-apply.json`) move with the pin. **Migration:** none; a host that reports
  what it certified against can read the stamp.
- **Core derives the evidence a host can offer for every ladder row** (Phase 480, `docs/`; DECISIONS.md D224) —
  class additive; no public surface moves. `docs/host-evidence-map.json`, written with its rendering
  `docs/host-evidence-map.md` by `render evidence-map`, gives every `proofs.json` row, in ladder order, the
  vector families whose cases its model answered (from the `answeredBy` stamps, with the case count) and the
  oracle functions that ask its model (from the oracle's own function table), at the grain of the model. It names
  the proved rows offered neither, grouped by model, as the worklist for new families, and the families no model
  answers. The suite holds both files to the render, and the derivation refuses a stamp or an oracle function
  naming a model no row states. **Migration:** none; a host's compliance declaration names rows from it.
