## 0.45.1 — DRAFT

**Slot class: additive.** The patch after the released `0.45.0`. It opens over `v0.45.0`, which is a consumer's
contract, so nothing rides it; the work in this slot is additive, which makes it a PATCH slot, and a breaking
member advances it to the `0.46.0` minor rather than riding it ([`STABILITY.md`](../../STABILITY.md), "Versioning
policy"). Phase 722 opens it. The conformance `kitVersion` stamp lines move to `0.45.1` with the slot, and the
corpus pin moves to the re-stamp of the declared copies.

**Each entry of this slot is a file of its own** (DECISIONS.md D274): add one as
`docs/releases/0.45.1/<class>/<name>.md`, with `<class>` one of `breaking`, `additive` or `internal` and `<name>`
`phase-<n>` (`phase-<n>-<word>` for a phase's second entry) or `pr-<n>`, holding the entry's bullet exactly as it
will print, and the act that closes the slot renders the entries here, a section per class.
