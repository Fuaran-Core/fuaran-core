## 0.40.0 — DRAFT

The minor after the released `0.39.0`. It opens over `v0.39.0`. Through the `0.x` line a breaking class rides a
minor ([`STABILITY.md`](../../STABILITY.md), "Versioning policy"). The slot opens on Phase 539's entry: the
IDL's field and enum records grow the canonical-form slots, which breaks a full record literal of either for F#
consumers. It carries three more breaking slices of the 2026-10-17 redesign pass (Phases 529, 527 and 524): the
DAG's write and fault surface retyped, `idl.json` read by one strict codec, and the generator's published types
lifted into one namespace.

### Breaking

- **The IDL field and enum records grow the canonical-form slots** (Phase 539, `Fuaran.Core.Idl`,
  `Fuaran.Core.Idl.Codegen`; DECISIONS.md D190). `IdlField` gains `Aliases: string list` and
  `Presence: PresenceCondition option` (the new union `WhenPresent` / `WhenAbsent` / `WhenEquals`), and
  `IdlEnum` gains `Aliases: (string * string list) list`; `Diff.Change` gains `FieldAliasesChanged`,
  `FieldPresenceChanged` and `EnumCaseAliasesChanged`, and `Diff.FieldSnap` / `Diff.EnumSnap` the members
  they read. Breaking for F# consumers only: a full record literal of `IdlField` or `IdlEnum` stops
  compiling (FS0764), and an exhaustive match over `Diff.Change` is incomplete. On the wire it is ADDITIVE:
  `idl.json` gains optional `aliases` and `presence` members, each omitted when empty, so a vocabulary that
  declares neither renders, decodes, encodes and generates byte-for-byte as before. A declared alias is
  accepted and normalised on decode and never encoded; a member whose presence condition fails is omitted
  on encode and dropped on decode; an empty-map or JSON default is now generated by the F#, TypeScript and
  F* backends instead of refused. The TypeScript codec and the F* model refuse an alias or a presence
  condition by name. New law set: `conformance/laws/canonical-form-laws.json`. The `api/` and `api/wire/`
  baselines of both packages move (wire class additive). **Migration:** add `Aliases = []` and
  `Presence = None` to an `IdlField` literal and `Aliases = []` to an `IdlEnum` literal (or build them
  with `Declare.enumOf` / `enumWith`), and give the three new `Diff.Change` cases an arm. The UI tier's
  cohort raise onto this release is where a vocabulary's presence and naming rules become declarations.

- **Every DAG write answers one `Written` record, and no `OpStream.Dag` answer carries a tuple** (Phase 529,
  `Fuaran.Core.OpStream.Dag`, `Fuaran.Core.OpStream`; DECISIONS.md D192) — class breaking (OpStream.Dag: removal
  and retype, 106 moves; OpStream: union-widening, 9 moves). The DAG's writes answer one `Dag.Written { Id; Dag
  }`, the replays run one fold over one drain, every cyclic history is one `Dag.Cyclic { Unplaced }`, the last
  string refusals are typed, and no `OpStream.Dag` answer carries a tuple. Content ids, lane bytes, total orders
  and fold verdicts are unchanged under `StreamConfig.canonical`. **Migration:**
  `Dag.appendOn/append/merge/mergeAll hashFn w ...` -> `Dag.<verb> (OpStream.canonical hashFn w) ...`, answering
  `Written` (`Ok(id, dag)` -> `Ok { Id = id; Dag = dag }`); `Dag.mergeWith` -> `Written list` (`Ok(ids, dag)` ->
  ids = `List.map _.Id`, dag = the last one's `Dag`, `Ok []` for an empty script);
  `appendChecked/mergeChecked/appendIf/appendVerified/mergeVerified hashFn w` -> `(OpStream.canonical hashFn
  w)`, `appendVerifiedWith/mergeVerifiedWith eq hashFn w` -> `eq (OpStream.canonical hashFn w)`, and
  `CheckedAppend.Id/.Dag` -> `.Written.Id/.Written.Dag`; `appendIndexed/mergeIndexed hashFn w` ->
  `(OpStream.canonical hashFn w)`, `IndexedAppend.Id/.Dag` -> `.Written.Id/.Written.Dag`; `appendOnLane hashFn w
  ...` -> `appendOnLane s ...` answering `LaneAppend { Written; Loaded }` (`Ok(id, loaded)` -> `.Written.Id`,
  `.Loaded`); `fromJsonlVerified hashFn w` / `loadLanesVerified hashFn w` / `verifyLanes hashFn w` -> one
  `Stream` argument; `loadLanes`/`loadLanesVerified` take `Dag.LaneText list` (`(lane, text)` -> `{ Lane = lane;
  Text = text }`), `lanesToJsonl` answers it, `tryLanesToJsonl` answers `Result<LaneText list, LaneWriteFault>`
  (`Error(lane, f)` -> `Error { Lane = lane; Fault = f }`); `Dag.TotalOrderFault.Cyclic unplaced` -> `Dag.Cyclic
  { Unplaced = unplaced }` (`totalOrderBy`, `totalOrder`, `ranks` answer `Result<_, Dag.Cyclic>`);
  `ReplayFault.CyclicHistory head` -> `ReplayFault.Cyclic { Unplaced }` (the head is among them);
  `ReplayAllFault.Cyclic unplaced` and `RehashFault.Cyclic unplaced` -> `Cyclic { Unplaced = unplaced }`;
  `Dag.tryTopoOrder` / `Dag.Reach.tryTopoOrder` -> `Result<string list, Dag.Cyclic>` (was a sentence);
  `Dag.prunable` -> `Result<_, Dag.PruneFault>` (`Error root` -> `Error(PruneFault.UnknownRoot root)`);
  `compactAt`/`compactFrom` -> `Dag.Compaction { Checkpoint; Dag }`;
  `toJsonlWithCheckpoints`/`tryToJsonlWithCheckpoints` -> `Dag.CheckpointedText { Lane; Sidecar }`;
  `fromJsonlWithCheckpoints` -> `Dag.Checkpointed { Dag; Checkpoints }`; `rehash` -> `Dag.Rehashed { Dag; Ids
  }`, `rehashLanes` -> `Dag.RehashedLanes { Loaded; Ids }`; `laneCollisions` -> `Dag.LaneCollision { Lane; Heads
  }` list; `disjointRoots` -> `Dag.DisjointRoot { Head; Root }` list; checkpoint sidecar refusals:
  `JsonlFaultReason.Refused "<sentence>"` -> `CheckpointNotAtSeqZero seq` / `CheckpointWithoutNode` /
  `CheckpointChainOnly` / `NotACheckpoint` (same rendered text; an exhaustive match over `JsonlFaultReason`
  gains four cases).

- **`idl.json` is one `Codec<Idl>`, read strictly, and no description is written for a vocabulary that declares
  none** (Phase 527, `Fuaran.Core.Idl`, `Fuaran.Core.Wire`; DECISIONS.md D193) — class breaking (removal and
  retype on Fuaran.Core.Idl; additive on Fuaran.Core.Wire; the wire is breaking, the idl.json description member
  is no longer written by default). The change: idl.json is written, read and described by one Codec<Idl>
  (Artifact.codec / codecWith, Artifact.schema, committed at conformance/idl/idl.schema.json). The
  omit-at-default rules are one table (Artifact.omitted). The reader is strict (an undeclared member is refused)
  and collects every defect at its path, with the encoding version still checked first and alone. A redefined
  closure/opaque/fn wire sentinel is refused. Proposal reads its types, defaults, optionalities and annotations
  through the artifact's codecs and refuses host-surface types, host-only slots, composite defaults and non-doc
  annotations as NotAdmitted at their path. A proposal may now carry the doc of a field, kind or union case it
  mints. Codec gains defaultField, entries, narrow, recursive and schemaDocument. render writes no description
  for a vocabulary that declares none (D40 amended). **Migration:** Artifact.defaultDescription has no
  replacement, and a vocabulary that wants a description declares one: Artifact.renderWith { Name = None;
  Description = Some text }. Artifact.defaultIdentity -> Artifact.unnamed (which has no description).
  Artifact.Identity.Description : string -> string option; wrap with Some. Artifact.identityOf / identityOfJson
  now answer DecodeError list; render the list with DecodeError.render where a string was used. Every generated
  artefact's vocabulary stamp moves once on regeneration. An idl.json with an unknown member is now refused,
  where it was read.

  With Phase 539 in the same slot, the codec declares `idl.json`'s `aliases` and `presence` members (each
  omitted when it says nothing, and `aliases` a row of `Artifact.omitted`), so the strict read admits them; a
  proposal that mints a member with either is `NotAdmitted` at its path, as the reader before the codec minted
  such a member with neither.

- **The generator's published types live in `Fuaran.Core.Idl.Codegen.Types`, and the emitters are one traversal
  per question** (Phase 524, `Fuaran.Core.Idl.Codegen`; DECISIONS.md D194) — class breaking
  (Fuaran.Core.Idl.Codegen). The generator's public types move to `Fuaran.Core.Idl.Codegen.Types`. The stability
  classifier's snapshot is typed, and its entry points fold from twelve to four. Two members and two generated
  accessors are removed. The emitters are rebuilt on one traversal per question with a printer per backend, and
  the runtime preludes are template files. Every other generated byte is identical (2142 pinned outputs over
  twelve vocabularies), with one named exception: the F# scaffold (`Gen.fsharpValue`) of a node authored without
  an envelope now fills the envelope's members (the old literal did not compile).
