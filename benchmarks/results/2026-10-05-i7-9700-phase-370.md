# Emitted TypeScript `encStr` timing — 2026-10-05 — i7-9700 — Phase 370 (before and after)

The generated TypeScript codecs (`src/Fuaran.Core.Idl.Codegen/Emit/TypeScript.fs`) carry their own
copy of the string-escaping rule: the prelude's `encStr`, which wrote every string one character at a
time. Phase 370 gives it Phase 365's fast path. One regex test (`/["\\\u0000-\u001f]/`) looks for an
escapable character, and a string with none is returned whole between quotes. The escaping loop below
the test is unchanged, so no emitted byte moves.

- **Machine:** Intel Core i7-9700 @ 3.00 GHz, 8 logical processors, Windows 10.0.26200, mains power.
- **node:** v25.9.0. **.NET:** SDK 10.0.401 (it emits the module; it is not timed).
- **Tree:** fuaran-core `phase-370`, based on `692c741`. "Before" is the module the unchanged emitter
  writes. "After" is the module the Phase 370 emitter writes. `diff` of the two modules is the one
  added line.

## Why these figures do not come from the 364 node leg

The shard asked for the "before" figure from Phase 364's node leg. That leg cannot give one. It times
the Fable-compiled `Fuaran.Core.Wire` harness (`benchmarks/Fuaran.Core.Wire.Benchmarks`). The emitted
codec is JavaScript text that the IDL generator writes, and no Fable compile reaches it. So the
emitted module is timed directly under node, over 364's corpora, with 364's sampling rule:

1. **The module.** A one-kind vocabulary (`Note` with two `str` fields, `label` and `body`) is emitted
   with `Gen.typescriptModule` from the built `Fuaran.Core.Idl.Codegen.dll`, through `dotnet fsi`. Its
   prelude is every generated codec's prelude.
2. **The corpora.** These are 364's `escape-free` and `escape-heavy` corpora: 1,000 strings of 64
   characters each, ported from `Corpus.fs`'s `text` generator, seeds `i * 7919`. The port was checked
   against the real corpora. The SHA-256 prefix of `'[' + strings.map(encStr).join(',') + ']'` under
   node equals that of `Json.render (Corpus.escapeFree ())` / `Json.render (Corpus.escapeHeavy ())` on
   .NET: `a70d6bff447e30e0` and `f45a5846260575bb`. This holds for both the before and the after
   module. A first draft of the port had a dropped backslash in the escape alphabet, and this check
   caught it (`9d8cb42d…` ≠ `f45a5846…`), so the check is known to go red.
3. **The cases.** `encStr` is timed over the 1,000 strings, which is the emitted function alone.
   `encodeNode` is timed over 1,000 nodes `{ id: 'nNNNN', kind: { $type: 'Note', label: s, body: s } }`,
   which is the whole emitted encoder: two field strings, the id, the tag and the keys.
4. **Sampling.** This is `Harness.fs`'s rule: two warm-up calls, then the calls per sample double
   until one sample spans 50 ms, then 15 samples. The figure is the median sample divided by the calls
   per sample, in milliseconds per call over the whole corpus.
5. **Same output.** Each run prints the fingerprints of both cases. They are identical before and
   after, on both corpora (`encodeNode`: `b3624c68222d6c09` and `00b8e8bb11acfc8d`).

The command is `node bench.mjs <emitted module> 15`. The before module was run twice, then the after
module twice, then the before module once more, back to back.

## Results (ms per call, median of 15)

| corpus | case | before 1 | before 2 | before 3 | after 1 | after 2 |
|---|---|---:|---:|---:|---:|---:|
| escape-free | `encStr` | 1.054 | 1.060 | 1.084 | 0.104 | 0.103 |
| escape-free | `encodeNode` | 3.653 | 3.613 | 3.981 | 1.150 | 1.107 |
| escape-heavy | `encStr` | 1.686 | 1.675 | 1.843 | 1.801 | 1.765 |
| escape-heavy | `encodeNode` | 5.348 | 5.322 | 5.349 | 5.223 | 5.175 |

## What the figures say

- **Clean strings.** `encStr` is 10.1 to 10.5 times faster. Each range runs from the fastest "before"
  over the slowest "after" to the slowest "before" over the fastest "after". The whole emitted encoder
  is 3.1 to 3.6 times faster on nodes whose strings hold nothing to escape. Most nodes a consumer
  writes are like that.
- **Escape-heavy strings.** About one character in four is escaped, so the regex matches near the
  start and the old loop runs. `encStr` is within the run-to-run spread: before 1.675 to 1.843, after
  1.765 to 1.801. `encodeNode` is about 2 per cent faster, because the clean id and keys take the fast
  path. The test does not cost a measurable amount when it fails.
- **Falsifier.** If the fast path did not run, the escape-free `encStr` figure would stay near 1 ms.
  If it changed a byte, the fingerprints would differ. Neither happened. The suite pins the bytes
  separately: `StringEscapeTests`' "emitted TypeScript encStr (Phase 370)" list runs the emitted
  function under node against `Json.render` and the one-character oracle. It covers the run-boundary
  corpus, the `StringEscapeVectors` alphabet and lone surrogates, and it has a mutated fast path that
  goes red.

## Consumers — what adopting it costs

The change is in the emitter. A generated module that is checked in keeps the old body until it is
regenerated by a Core build that carries this phase. That needs a version cut of `0.35.0` (or later)
and a pin raise in the consumer (DECISIONS.md D2, D76, D55). Nothing outside this repository is
edited here. A grep of the downstream checkouts on the measuring machine (2026-10-05) for the old body
(`code.toString(16).padStart(4, '0')`, with `node_modules`, `bin` and `obj` excluded) found:

- **Emitted, so regeneration reaches it:** one downstream consumer's worked example,
  `recipes/05-a-fresh-vocabulary-through-the-idl-to-a-second-host/host-ts/generated.mjs`, emitted by
  `Fuaran.Core.Idl.Cli` 0.30.0, which is pinned in the example's own tool manifest. It adopts by
  raising that pin and regenerating. Its bytes on the wire do not change.
- **Hand-written copies of the same loop, which regeneration does not reach:**
  `fuaran-live/app/showcase/rosetta-hosts.ts` (`quote`), and the escapers in `fuaran-ts`
  `packages/ops/src/encode.ts`, `packages/ops/src/dag.ts` and `packages/core-twins/src/actor.ts` (plus
  their `dist/*.map` build outputs). These are not this phase's emitted code. Each would need its own
  change in its own repository.

## The script

`bench.mjs`, verbatim:

```js
// Phase 370 - times the EMITTED encStr, and an emitted codec's encodeNode, under node.
// Usage: node bench.mjs <emitted module .mjs> [runs]
import { readFileSync } from 'node:fs';
import { createHash } from 'node:crypto';
import { pathToFileURL } from 'node:url';
import { resolve } from 'node:path';

const modPath = resolve(process.argv[2]);
const runs = parseInt(process.argv[3] || '15', 10);
const src = readFileSync(modPath, 'utf8');
const m = /const encStr = \(s\) => \{[\s\S]*?\n\};\n/.exec(src);
if (!m) throw new Error('no encStr in ' + modPath);
const encStr = new Function(m[0] + 'return encStr;')();
const { encodeNode } = await import(pathToFileURL(modPath).href);

const next = (x) => (x * 1103 + 12345) % 65521;
const plain = "abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789 -_.,:;/()[]{}#@!?+=*&%$~|<>'éü中";
const escaped = "\"\\\n\r\t\u0001\u001f";
const text = (heavy, len, seed) => {
  let x = seed % 65521; let s = '';
  for (let k = 0; k < len; k++) {
    x = next(x);
    s += (heavy && x % 4 === 0) ? escaped[Math.trunc(x / 4) % escaped.length] : plain[x % plain.length];
  }
  return s;
};
const corpus = (heavy) => Array.from({ length: 1000 }, (_, i) => text(heavy, 64, (i + 1) * 7919));
const corpora = [['escape-free', corpus(false)], ['escape-heavy', corpus(true)]];

const medianMs = (f) => {
  f(); f();
  let calls = 1;
  for (;;) {
    const t0 = performance.now(); for (let c = 0; c < calls; c++) f(); const dt = performance.now() - t0;
    if (dt >= 50) break; calls *= 2;
  }
  const samples = [];
  for (let r = 0; r < runs; r++) {
    const t0 = performance.now(); for (let c = 0; c < calls; c++) f(); samples.push((performance.now() - t0) / calls);
  }
  samples.sort((a, b) => a - b);
  return samples[Math.floor(samples.length / 2)];
};
const sha = (s) => createHash('sha256').update(s, 'utf8').digest('hex').slice(0, 16);

console.log(`node ${process.version}; module ${modPath}; runs ${runs}`);
for (const [name, strs] of corpora) {
  const nodes = strs.map((s, i) => ({ id: 'n' + String(i).padStart(4, '0'), kind: { $type: 'Note', label: s, body: s } }));
  const arr = () => '[' + strs.map(encStr).join(',') + ']';
  const enc = () => nodes.map(encodeNode).join('\n');
  console.log(`FP ${name} encStr-array ${sha(arr())}`);
  console.log(`FP ${name} encodeNode ${sha(enc())}`);
  let sink = 0;
  const tStr = medianMs(() => { for (const s of strs) sink += encStr(s).length; });
  const tNode = medianMs(() => { for (const n of nodes) sink += encodeNode(n).length; });
  console.log(`ROW ${name} encStr ${tStr.toFixed(3)}`);
  console.log(`ROW ${name} encodeNode ${tNode.toFixed(3)}`);
  if (sink < 0) console.log(sink);
}
```

The module is emitted by an F# script that references the built `Fuaran.Core.Wire.dll`,
`Fuaran.Core.Idl.dll` and `Fuaran.Core.Idl.Codegen.dll`. It declares the vocabulary with `Kinds =
[ { Tag = "Note"; Category = "leaf"; Fields = [ label: TStr Required; body: TStr Required ] } ]` and
every other member empty (`WireShape.Default`, `HardenPolicy.Undeclared`). Then it writes
`Gen.typescriptModule idl [ "Note" ]` to the file.
