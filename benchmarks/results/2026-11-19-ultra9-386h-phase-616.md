# A parse copies no number or literal token — 2026-11-19 — Core Ultra 9 386H — Phase 616

Phase 616 asked whether `Json.parse` pays for a substring per number token, per `true`, `false` or `null`, and
per object member on the path that erases a member `null`, and, if it does, for the .NET path to read those tokens
in place. The review that filed it estimated the cost by reading the code; this file measures it. The before
figures were taken first, on the tree the phase was cut from, before any change.

- **Machine:** Intel Core Ultra 9 386H, 16 logical processors, Windows 10.0.26300. Other builds were running on
  the machine; the timed runs were taken under a shared benchmark lock that kept every other timed benchmark run
  off it, but builds were not excluded. The allocation column is the measure the phase is about, and it does not
  depend on load.
- **.NET:** runtime 10.0.8, SDK 10.0.203, Release build of `Fuaran.Core.Wire`.
- **Harness:** [`json-parse-phase-616.fsx`](json-parse-phase-616.fsx), beside this file, run as its header says,
  one case per process. It checks that every parse answers the value its text was rendered from before it times
  anything.
- **Cases:** `floats` and `state` are the wire benchmark's corpora of those names; `state` carries no number or
  literal token and is the control. `ints` is 10,000 integer tokens, `literals` 10,000 `true` / `false` tokens,
  and `members` 2,000 objects of five integer members read under `ReadOptions.tolerantOfNull`.
- **Columns:** Phase 607's: wall time per call in milliseconds (mean, median, p95), bytes the calling thread
  allocated per call, and generation-2 collections per call. `token bytes` is what one string per token costs
  (24 bytes of header and length, two per unit, rounded up to 8) summed over the tokens the parse meets, the
  member look-ahead's four-unit string included.
- **Threshold, written before the first run:** the change is material if the token strings are at least 10 % of
  the bytes a parse allocates on one of `floats`, `ints` or `literals`; below that on all three, the phase closes
  with this file and no code change.
- **Trees:** before, `95b1a2f1`.
